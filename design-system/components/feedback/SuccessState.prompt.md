The end-of-flow confirmation: copper ring, one heading, one calm sentence, one action.

```jsx
<SuccessState title="حساب شما ساخته شد" description="حالا اولین پروژه‌تان را تعریف کنید.">
  <Button variant="primary" fullWidth>ساخت پروژه</Button>
```

No confetti, no green checkmark badge, no exclamation marks. The copper ring is the only celebration CHIDA uses.
