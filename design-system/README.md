# دیزاین سیستم چیدا

این پوشه نسخهٔ واردشده و قابل نگهداری دیزاین سیستم CHIDA است که از خروجی Claude Design در تاریخ ۱۴۰۵/۰۶/۰۵ استخراج شده است.

## محتوا

- `tokens/`: رنگ، تایپوگرافی، فاصله، شعاع، حرکت و گرید
- `components/`: کامپوننت‌های مرجع React و قراردادهای آن‌ها
- `assets/icons/`: آیکون‌های SVG مرجع با مجوز Lucide
- `assets/fonts/`: وب‌فونت IRANYekanX و فایل مجوز همراه آن
- `guidelines/`: شیت‌های مرجع قواعد بصری
- `styles.css`: ورودی اصلی CSS خروجی طراحی
- `export-readme.md` و `export-manifest.json`: توضیح و مانیفست خروجی اصلی

## قواعد تثبیت‌شده

- محصول فارسی، RTL و موبایل‌فرست است.
- رنگ‌ها به خنثی‌های گرم، مسی شاخص و قرمز خطا محدود می‌شوند.
- Light و Dark هر دو شهروند درجه‌یک دیزاین سیستم هستند.
- وزن‌های اصلی فونت ۴۰۰، ۵۰۰ و ۶۰۰ هستند.
- هر حساب فقط یک نقش دارد: سازنده یا تأمین‌کننده؛ نقش دوم و تغییر نقش وجود ندارد.
- مسیر سازنده: انتخاب نقش ← کد دعوت ← موبایل ← OTP ← خانهٔ چت.
- مسیر تأمین‌کننده در این نسخه فقط به‌صورت «به‌زودی» نمایش داده می‌شود.

پروتوتایپ اجرایی در پوشهٔ `prototype/` از همین توکن‌ها و قواعد استفاده می‌کند. نمونه‌های قدیمی داشبوردی و فایل‌های وابسته به runtime اختصاصی Claude Design عمداً وارد نسخهٔ اجرایی نشده‌اند.
