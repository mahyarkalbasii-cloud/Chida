# CHIDA — چیدا

چیدا همکار هوشمند و منبع‌دار بازار ساخت ایران است: یک فضای گفت‌وگومحور که نیاز سازنده را به کار، سند، تصمیم و شیء ماندگار تبدیل می‌کند و جریان خرید را تا مقایسه، مذاکره و تبادل رضایتمندانهٔ اطلاعات تماس پیش می‌برد.

منبع حقیقت محصول [سند مادر تعریف محصول](./CHIDA-Product-Definition-FA.md) است. فهرست قابلیت‌های بعدی سازنده در [بک‌لاگ سازنده](./BUILDER-FEATURE-BACKLOG-FA.md) نگه‌داری می‌شود.

## وضعیت فعلی

پروتوتایپ فعلی یک اپ فارسی RTL، واکنش‌گرا، Mobile-first و Dark-only است و این مسیرها را پوشش می‌دهد:

- انتخاب نقش با قاعدهٔ «یک حساب، یک نقش»؛
- ورود سازنده با کد دعوت، شمارهٔ موبایل و OTP ازپیش‌پرشده؛
- خانهٔ چت‌محور با پروژهٔ فعال، Composer، حالت پاسخ، فایل، صدا، ابزارها و Drawer راست؛
- Build برای تعریف، پیش‌نمایش مجوزها و نصب آزمایشی پلاگین + اسکیل در پروژه؛
- Brief با برنامهٔ روزانه یا هفتگی و خلاصهٔ ماندگار در مرورگر.

Build، Brief، OTP، چت و نصب در این مرحله نمایشی و محلی‌اند و هیچ اقدام بیرونی یا نصب واقعی انجام نمی‌دهند.

## اجرای محلی

```bash
cd prototype
npm ci --prefer-offline --no-audit --no-fund
npm run dev
```

سپس `http://127.0.0.1:5173/` را باز کنید.

مقادیر آمادهٔ ورود:

- کد دعوت: `CHD-4K9P`
- موبایل: `09123456789`
- OTP: `123456`

## تست و ساخت

```bash
cd prototype
npm run check:runtime
npm run build
npm run test:app
npm run test:runtime
npm run test:sites
```

خروجی Cloudflare Pages در `prototype/dist/client` و بستهٔ ChatGPT Sites در `prototype/dist` آماده می‌شود.

## مرز محصول

چیدا بازار عمومی، تضمین‌کنندهٔ معامله، مجری پرداخت/قرارداد/حمل، ERP، نرم‌افزار حسابداری رسمی یا عامل خودمختار بدون تأیید انسان نیست. خروجی حساس باید قابل‌ردیابی، منبع‌دار، نسخه‌دار و قابل‌اصلاح باشد.
