# پروتوتایپ موبایل CHIDA

پروتوتایپ واقعی و کلیک‌پذیر مسیر ورود سازنده تا خانهٔ چت‌محور چیدا.

## فلو فعال

1. انتخاب نقش؛ هر دو نقش قابل انتخاب‌اند، اما تأمین‌کننده فعلاً پیام «به‌زودی» می‌بیند.
2. کد دعوت سازنده: `CHD-4K9P`
3. موبایل نمونه: `09123456789`
4. OTP نمونه: `123456`
5. ورود به پروژهٔ نمونهٔ «برج نیلوفر» و خانهٔ چت.

برای تست خطا می‌توان از `CHD-0000` یا OTP برابر `000000` استفاده کرد.

## اجرا

```bash
npm ci --prefer-offline --no-audit --no-fund
npm run dev
```

## کنترل کیفیت

```bash
npm run check:runtime
npm run build
npm run test:sites
```

فایل‌های app-specific فقط در `src/Prototype.tsx` و `src/prototype.css` قرار دارند. runtime قاب موبایل، کیبورد و تست میزبانی از template رسمی Product Design حفظ شده است.
