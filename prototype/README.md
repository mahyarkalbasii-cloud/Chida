# پروتوتایپ واکنش‌گرای CHIDA

پروتوتایپ واقعی، کلیک‌پذیر و تمام‌صفحهٔ مسیر ورود سازنده تا خانهٔ چت‌محور چیدا. رابط Mobile-first است، اما روی دسکتاپ نیز به‌صورت یک اپ واکنش‌گرا اجرا می‌شود و قاب نمایشی موبایل ندارد.

## فلو فعال

1. انتخاب نقش؛ هر دو نقش قابل انتخاب‌اند، اما تأمین‌کننده فعلاً پیام «به‌زودی» می‌بیند.
2. کد دعوت سازنده: `CHD-4K9P`
3. موبایل نمونه: `09123456789`
4. OTP نمونه: `123456`
5. ورود به پروژهٔ نمونهٔ «برج نیلوفر» و خانهٔ چت.
6. Build برای تعریف و نصب آزمایشی پلاگین + اسکیل پروژه.
7. Brief روزانه یا هفتگی از منوی سمت راست.

برای تست خطا می‌توان از `CHD-0000` یا OTP برابر `000000` استفاده کرد.

## اجرا

```bash
npm ci --prefer-offline --no-audit --no-fund
npm run dev
```

## کنترل کیفیت

```bash
npm run check:runtime
npm run build
npm run test:app
npm run test:runtime
npm run test:sites
```

فایل‌های app-specific فقط در `src/Prototype.tsx` و `src/prototype.css` قرار دارند. runtime تست موبایل از template رسمی Product Design حفظ شده، اما chrome نمایشی آن در مسیر واقعی اپ پنهان است. Build، Brief، چت و نصب در این مرحله فقط داخل مرورگر شبیه‌سازی می‌شوند.
